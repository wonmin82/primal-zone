# 명령 어휘와 별칭 기준

실행 어휘의 SSOT는 각 Command의 `key`·`aliases`, `commands/aliases.py`의 전역 단축어와 `content/directions.py`의 방향이다. 도움말의 표시 입력은 `commands/help_contracts.py`와 개별 명령의 `help_sections`를 사용한다.

| 정식 명령 | 사용자 별칭 | 제거한 이전 입력 |
| --- | --- | --- |
| 봐 | 본, 보, ASCII 0x60 백틱 | 보기, look, l, 둘러보기 |
| 도움 | 도움말 | 안내, ? |
| 점수 | 상태, 상, 점 | stat |
| 가진거 | 가진, 소, 소지, 소지품 | 가방, i, 인벤토리 |
| 누구 | 누 | 접속자, who |
| 때려 | 쳐, 공격 | 사냥, attack |
| 목록 | 품목, 품, 목, 메뉴 | 상품 |
| 사 | 구입 | 구매, buy |
| 팔아 | 팔, 판 | 판매, sell |
| 쏴 | 없음 | 사격, shooting |
| 지도 | 지 | map |
| 경험치 | 경 | 없음 |
| 장비 | 장 | 없음 |
| 착용 | 입어, 입 | wear |
| 벗어 | 벗 | remove |
| 가져 | 집 | 없음 |
| 줄임말 | 준말 | 없음 |
| 가치 | 얼마 | value |

대상·번호·조사는 별칭에서도 그대로 전달한다: `갈퀴사냥룡 2 쳐`, `보급관에게 붕대 구입`, `붕대 집`. 정식 명령·별칭으로 요청한 도움말은 같은 정식 페이지를 표시한다.

8방향 초성에 `ㅇ → 위`, `ㅁ/아 → 아래`를 더한다. 실제 출구가 있어야 이동하며 `나가`는 귀환으로 바꾸지 않는다. `시`는 `시체에서 모두 가져`, `시2`~`시5`는 `시체 N에서 모두 가져`다. 시야·번호·보호 시간·소유권·파티 분배를 그대로 적용한다.

실제 명령과 Exit가 전역 고정·인자형 단축어보다 우선하고 개인 줄임말이 마지막이다. 잠긴 실제 명령도 개인 정의로 우회할 수 없다. 새 예약 이름과 충돌하는 저장 정의는 `_개인` 이름으로 보존하고 정확한 개인 호출 동사만 함께 옮긴다. 현재 장소의 특수 Exit와 충돌해도 Exit가 우선한다.

Evennia 기본 `look`, `inventory`, `help`, `who`는 새 사용자 명령과 중복되지 않도록 CmdSet에서 제거한다. 게임의 이동·접속 내부 관찰은 `at_look`을 직접 사용하므로 제거한 사용자 별칭을 요구하지 않는다. Account CmdSet에서도 기본 관찰·도움·접속자 명령을 제거해 게임의 새 이름을 우회하지 않는다. 이 범위의 영문 사용자 별칭에 엔진 호환 예외는 없다.

## 저장 정의 변환

46-A는 profile v11을 유지하고 변환 함수만 준비한다. `정보`의 기존 상태 조회 의미와 `진료`의 기존 의료 기능은 각각 46-B·C에서 한 번에 전환한다. 모든 새 명령이 구현된 뒤 최종 프로필 버전을 전환한다.

v7 이하의 `회복`은 먼저 기존 v8/v10 변환을 거쳐 붕대 응급처치 의미를 보존한다. v11 이하의 `정보`는 `점수`, `진료`는 새 `회복`, `사격`은 `쏴`로 변환한다. 새 버전의 `회복`은 유료 의료 의미다. 채팅·객체명·변수는 바꾸지 않고 정의의 동사 자리만 변환한다. 불명확하거나 비정상인 원본은 삭제하지 않고 기존 비활성/관리자 복구 안내를 유지한다.
