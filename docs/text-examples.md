# 텍스트 출력 예

아래는 의미별 색을 제외한 실제 출력 형식이다. 검증용 일반 탐사자의 조회·사냥 결과를 발췌했으며 수치는 당시 상태다. 색을 제거해도 내용이 유지된다. 색상표와 전달 구조는 [설계 문서](architecture.md#텍스트와-의미별-색상)를 참고한다.

## Room · 적이 있는 초지

```text
────────────────────────
바람 부는 초지
────────────────────────

무릎 높이의 풀 사이로 작은 발자국이 이어진다. 첫 사냥에 적당한 곳이다.

  북
   │
[현재] ─ 동
   │
  남

어린청소룡이 주변을 경계하며 서성이고 있다.
```

## NPC가 있는 Room

```text
윤대장은 낡은 지도를 펼쳐 놓고 탐사대를 기다리고 있다.
탐사대 훈련관은 탐사자의 전투 기록을 살피며 훈련 계획을 세우고 있다.
문장검증가는 이곳에서 주변을 살피고 있다.
```

## 전투 · 처치 · 보상

```text
어린청소룡이 달려들어 4의 피해를 입혔다.
낡은마체테로 어린청소룡을 공격해 9의 피해를 입혔다.
어린청소룡이 더는 버티지 못하고 바닥에 쓰러졌다.
이번 사냥으로 경험치 11, 4크레딧을 얻었다.
```

보상은 두 파티원이 실제 공격에 참여한 사냥에서 받은 개인 몫이다. 적 이름만 적색, 무기만 아이템색, XP·크레딧만 보상색이며 조사와 일반 문장은 기본색이다.

## 전리품 획득

```text
회수부품 1개는 이번 순번인 문장검증나에게 돌아갔다.
```

직접 배정된 아이템을 회수하면 `시체를 뒤져 회수부품 1개를 챙겼다.`로 표시한다. 누가 명령을 입력했는지와 실제 수령인이 다를 수 있다는 기존 규칙을 그대로 드러낸다.

## 대상 보기

```text
────────────────────────
어린청소룡
────────────────────────

작은 몸집의 육식 공룡이다. 날카로운 이빨을 드러내며 주변을 경계한다.
체력 24 / 24

가능한 행동 : 공격
```

```text
────────────────────────
어린청소룡의 시체
────────────────────────

남아 있는 물건을 살펴본다.

회수부품 ×1 · 배정: 문장검증나 (회수 가능)

가능한 행동 : 가져
```

## 상태

```text
────────────────────────
문장검증가의 상태
────────────────────────

등급        Lv.1
체력        60 / 60
경험치      0 / 60
크레딧      20
처치        0

공격        9
방어        1

[ 특성 ]
힘 10 · 민첩 10 · 체질 10 · 지혜 10

[ 착용 장비 ]
무기        낡은마체테
방어구      탐사조끼
```

## 능력

```text
[ 특성 ]

힘          10 (기본 10 + 투자 0)
  투자 2점마다 공격 +1
민첩        10 (기본 10 + 투자 0)
  투자 3점마다 방어 +1
체질        10 (기본 10 + 투자 0)
  투자 1점마다 최대 HP +4
지혜        10 (기본 10 + 투자 0)
  투자 1점마다 붕대 회복 +2

남은 특성 포인트 : 4

[ 숙련 ]

무기        Rank 0
방어        Rank 0
응급처치    Rank 0
```

## 기술

```text
강타        Rank 1 / 3
  다음 공격의 피해 배율 증가
  다음 수련 : Lv.1 · 1점 · 4크레딧

방어        Rank 1 / 3
  기본 공격을 유지하며 다음 피해 감소
  다음 수련 : Lv.1 · 1점 · 4크레딧

응급치료    Rank 1 / 3
  붕대 회복량 증가; 전투 중 기본 공격 대체
  다음 수련 : Lv.1 · 1점 · 4크레딧

남은 기술점수 : 2
교관에게 기술이름 배워
```

## 가방

```text
[ 장비 ]
낡은마체테        ×1 [착용]
탐사조끼          ×1 [착용]

[ 소모품 ]
붕대              ×3
```

## 상점

```text
붕대              8 크레딧
강철마체테        60 크레딧
  교환 : 회수부품 6개
강화조끼          65 크레딧
  교환 : 회수부품 6개
탐사카빈          130 크레딧
  교환 : 회수부품 12개
```

390px에서는 긴 설명이 자연스럽게 줄바꿈한다. 고정된 너비의 표나 HTML 링크를 사용하지 않으며 명령 실행은 입력창과 기존 버튼에서 한다.
