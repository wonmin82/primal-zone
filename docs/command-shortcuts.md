# 개인 줄임말과 묶음 명령

이 문서는 줄임말 확장 기획 v1.14의 현재 계약이다. 프로필 버전은 **11**이며 기획 버전과 별개다. 아래 과거 검증 기록은 당시 실행 의미와 결과를 보존한다.

## 공식 문법

| 기능 | 입력 |
| --- | --- |
| 전체 조회 | `줄임말` |
| 개별 조회 | `이름 줄임말` |
| 등록·수정 | `이름 정의 줄임말` |
| 개별 삭제 | `이름 해지` |
| 전체 삭제 요청 | `모두 삭제 줄임말` |
| 전체 삭제 확인 | `모두 삭제 확인 줄임말` |
| 전역 단축어 조회 | `전역 줄임말` 또는 `단축어` |
| 도움말 | `줄임말 도움말`, `해지 도움말`, `해 도움말`, `단축어 도움말` |

```text
장확 장비 줄임말
정찰 $1 보기, 상태 해 줄임말
북 정찰
집 $* 가져 줄임말
시체에서 회수부품 모두 집
전달 $1에게 $2 줘 줄임말
철수 20칩 전달
동작 북 $1 줄임말
보기 동작
실행 $* 줄임말
상태 실행
인사 안녕, 반가워 말 줄임말
인사, 상태 해
장확 줄임말
장확 해지
```

특수 관리 입력은 전체 삭제 확인 → 전체 삭제 요청 → 전역 목록 → 전체 목록 → 개별 조회 → 일반 등록·수정 순서로 판정한다. 도움말은 관리 입력보다 우선한다. 전치형 관리 문법은 제공하지 않는다. `모두`는 유효한 이름이다. `모두 해지`는 그 이름 하나만 삭제하며 다른 정의를 연쇄 삭제하지 않는다.

이름은 한글 완성형·자모·영문·숫자·밑줄 1~20자다. 공백과 콤마는 금지하고 영문은 casefold로 정규화한다. 실제 명령·별칭·Exit·전역 단축어·기술명·미래 예약 명령 및 `줄임말/해지/해/전역`을 새 이름으로 사용할 수 없다. 잠긴 실제 명령도 예약 이름이다.

## 원본 정의와 로컬 검증

캐릭터별 `profile["command_shortcuts"]`만 영속 저장한다. 신규 형식은 다음과 같다.

```python
{"장확": "장비", "정찰": "$1 보기,  상태 해", "실행": "$*"}
```

정의의 앞뒤 공백만 제거하고 내부 공백·문장부호를 보존한다. AST·토큰·계획·참조 그래프는 저장하지 않는다. 같은 이름을 유효한 정의로 등록하면 전체 정의를 원자적으로 교체한다. 검증·저장 실패 시 기존 키와 값을 유지한다.

등록은 해당 정의의 이름·길이·단일/묶음 구조·빈 세그먼트·변수 문법·위치 변수 연속성만 검사한다. 실제 명령 존재 여부, 행동 위치, 다른 정의, 순환·역참조·전체 확장량은 검사하지 않는다. `A B 줄임말`과 `B A 줄임말`은 등록할 수 있으며 실제 순환 경로가 선택될 때 중단한다.

캐릭터당 최대 100개다. 신규 이름 추가만 제한하며 상한 도달 후에도 기존 이름 조회·교체·삭제를 허용한다. 구형 데이터가 이미 상한을 넘으면 삭제하지 않는다. 리스트·None 등 비활성 항목도 개수에 포함한다.

## 단일·묶음 문법과 변수

`장비`, `$*`, `북 $1`, `$1에게 $2 줘`, `@help $1`은 단일 세그먼트다. 마지막 독립 행동 `해`와 두 개 이상의 콤마 세그먼트가 있으면 묶음이다. `북 보기, 상태 해`는 `북 보기`와 `상태`로 나뉜다. 빈 정의·빈 세그먼트·`상태 해`는 오류다.

`안녕, 반가워 말`과 `'안녕, 반가워`는 각각 단일 채팅이다. 묶음 내부 리터럴 콤마의 이스케이프나 따옴표 그룹핑은 없다. 필요하면 채팅을 단일 줄임말로 저장하고 묶음에서 호출한다. **명령 경계는 치환 전에 정하고 치환 후에는 콤마로 재분할하지 않는다.**

| 토큰 | 의미 |
| --- | --- |
| `$1`~`$9` | 공백으로 분리한 위치 인자 |
| `$*` | 전체 인자를 공백 한 칸으로 연결 |
| `$$` | 리터럴 `$` |

`$0`, `$10`, `$abc`, 단독 `$`는 오류다. `$10`을 `$1`과 `0`으로 나누지 않는다. `$$1`은 리터럴 `$1`이다. `$*`가 없으면 `$1`부터 최대 번호까지 연속해야 하며 인자 부족·초과를 거절한다. `$*`는 전체 인자를 소비하지만 빈 인자는 거절한다. `$* $2`처럼 혼합하거나 같은 변수를 반복할 수 있다. 변수 없는 정의에 인자를 줄 수 없다.

사용자 인자 속 `$1/$*`는 재치환하지 않는다. `인사 $$You()라고 말해 말 줄임말`은 채팅에 리터럴 `$You()`를 전달한다. 개행·제어문자는 금지한다. 따옴표로 여러 단어를 한 인자로 묶지 않는다.

치환으로 행동 이름을 바꿀 수 있다. `동작 북 $1`의 `보기 동작`은 관찰 명령 `북 보기`를 선택한다. 최종 문자열의 전치형·후치형은 기존 파서가 판단한다. `실행 $*`에 `상태, 장비 해 실행`을 넣으면 실제 `해` Command 선택을 감지해 새 묶음을 거절한다. `$* 말`이 같은 인자를 받으면 채팅 Command이므로 허용한다.

### 실제 엔진 명령과 충돌하는 인자

실제 명령 문법이 먼저다. 예를 들어 `도움 @help $1 줄임말`은 등록할 수 있지만 **`look 도움`은 실제 엔진 `look` 입력으로 선택된다.** 이를 `@help look`으로 바꾸는 예시는 실제 명령 우선 정책과 양립하지 않는다. 충돌하지 않는 `장비 도움`은 `@help 장비`를 선택할 수 있다. 엔진 전치형 명령과 충돌하는 인자는 그 엔진 명령을 직접 사용하거나 충돌하지 않는 별도 무인자 정의로 등록한다. 잠긴 명령의 충돌도 개인 정의로 우회하지 않는다. Exit는 무인자 이동 문법만 일치시킨다. 따라서 `북 정찰`처럼 유효한 후치형 개인 호출은 방향 인자를 받을 수 있으며, 치환 결과가 실제 `북` 이동을 선택하면 그 Exit의 권한·인자 규칙을 다시 적용한다. 인자가 붙은 custom Exit 후보도 개인 호출을 숨기지 않는다.

## 선택·지연 확장·부분 실행

1. 최상위 입력마다 개인 정의의 사본을 한 번 확보한다.
2. 다음 세그먼트 직전에 Evennia가 현재 위치·객체·계정·세션에서 CmdSet을 다시 합성한다.
3. 실제 명령/Exit → 기존 정적 전역 단축어 → 활성 개인 정의 → 비활성 정의 오류 → 알 수 없는 명령 순서로 선택한다. 엔진 명령의 기존 특별 우선순위와 채팅·후치형 관찰은 유지한다.
4. 실제 문법 일치는 lock 검사 전에도 확인한다. 여러 단어 행동 별칭은 인자 없이 정확히 입력한 경우와 인자가 앞에 오는 경우 모두 실제 명령으로 선택한다. 접근 거부를 개인 정의 선택 사유로 사용하지 않는다.
5. 개인 정의가 선택된 경우에만 구문 분석·인자 치환·하위 삽입을 한다. 선택되지 않은 잘못된 정의는 파싱하지 않는다.
6. 실제 선택한 Command 인스턴스를 엔진 `cmdhandler(cmdobj=...)`로 실행한다. 문자열을 다시 파싱해 다른 명령을 실행하지 않는다. 기존 권한·pre/parse/func/post hook을 유지한다.

이동 후 등장한 실제 명령이 개인 이름과 같으면 실제 명령이 우선한다. 사라졌다면 최초 개인 스냅샷의 정의를 사용한다. 묶음 안에서 등록·수정·삭제해도 현재 스냅샷은 바뀌지 않고 다음 최상위 입력부터 반영한다. CmdSet의 동적 갱신은 Evennia의 객체·CmdSet identity와 캐시 계약을 따른다. 같은 구조 identity로 명령 함수만 덮어쓰는 캐시 우회는 구현하지 않는다.

각 대기 항목은 불변 조상 경로를 가진다. 조상 이름 재호출은 순환이지만 형제의 같은 이름 반복은 허용한다. 전체 참조 그래프·전면 flatten·역참조 검증은 없다.

치환한 문자열은 세그먼트를 꺼낼 때만 생성한다. 토큰별 출력 길이를 먼저 합산하고 축적 중에도 검사하여 대용량 반복 변수를 실제 문자열로 만들지 않는다. 개인 호출용 중간 문자열은 인자 2,000자·이름 20자·구분 공백을 포함한 2,021자로 보호한다. 이는 실제 최종 명령 합계 1,000자와 별개이며, 최종 Command가 선택되면 남은 누적 예산을 디스패치 전에 검사한다. 다음 세그먼트의 치환 오류나 11번째 실행 제한은 앞선 정상 동작을 되돌리지 않는다. 개인 중첩과 인자형 전역 정의도 같은 치환 경로를 사용한다.

| 한도 | 값 |
| --- | --- |
| 이름 | 20자 |
| 저장 개수 | 100개, 신규 추가만 제한 |
| 원본 정의 | 2,000자, 실행 시도 때도 검사 |
| 호출 인자 | 2,000자 |
| 직접 즉석 묶음 입력 | 접미 `해` 포함 2,000자 |
| 실제 하위 실행 시도 | 10개 |
| 개인 정의 깊이 | 최상위 1부터 최대 5 |
| 최종 하위 문자열 합계 | 1,000자 |

묶음·개인 래퍼 및 정의 확장은 실행 수에 포함하지 않는다. 게임·엔진·관리·채팅·Exit·권한 거부·알 수 없는 명령은 포함한다. 전역 변환 후 문자열을 합산하며 구분 콤마와 최상위 `해`는 제외한다. 11번째는 디스패치 직전에 차단하고 앞의 10개 결과는 유지한다. 제한은 일반 게임 입력·채팅 전체에 적용하지 않는다.

정의 문법·변수·순환·깊이·실행량·비활성 값·새 묶음·지원하지 않는 재확장·완료 불명확·소유권 상실은 남은 실행을 중단한다. 대상 없음·자원 부족·인자 오류·통상 lock 거부·알 수 없는 명령은 해당 명령만 실패하고 다음을 계속한다. **묶음 전체는 트랜잭션이 아니며 이미 끝난 이동·아이템 조작은 되돌리지 않는다.**

일반 조회·등록·수정·개별 삭제·전역 조회는 내부에서 허용한다. `상태, 장확 장비 줄임말 해`는 단일 정의 등록이다. 콤마 포함 정의는 직접 등록만 허용하며 입력 경계를 추측해 복원하지 않는다.

## 실행 수명·프롬프트·지원 완료 계약

캐릭터당 하나의 실행 컨텍스트만 사용한다. 시작 검사와 활성화 사이에 yield하지 않고 같은 캐릭터의 다른 세션도 중복 시작을 거절한다. 일반 입력은 잠그지 않는다. 상태는 ACTIVE → STOPPING/FINISHED이며 정상·오류 종료는 재사용 가능한 상태로 정리한다.

원래 세션·계정·puppet 제어권을 매 단계와 비동기 hook 완료 후 확인한다. 로그아웃·unpuppet·세션 종료·소유권 상실은 남은 실행을 취소한다. 다른 세션으로 이전하지 않는다. 늦은 완료 콜백도 재개하지 않는다. 출력 깊이를 정리하고 살아 있는 정상 최상위 입력에는 최종 프롬프트를 한 번만 보내며 종료된 세션에는 새 프롬프트를 보내지 않는다.

Evennia 6.1.0은 pre/parse/post Deferred를 기다리지만 `func()`의 Deferred나 progressive generator 전체 수명을 기다리지 않는다. 일반 동기 명령과 엔진이 완료를 기다리는 비동기 hook만 지원한다. generator/coroutine 함수, 알려진 입력 대기·제어권 전환·직접 Deferred 참조, 명시적으로 완료 미보장을 선언한 명령은 실행 전에 거절한다. 정적 검사에서 드러나지 않은 helper가 Deferred/generator/coroutine을 실제 반환하면 `func()` 호출 후 방어적으로 남은 실행을 중단한다. 이는 helper의 선행 부작용을 막거나 되돌린다는 보장이 아니다. 엔진 도움말은 페이지 입력 가능 모드에서 거절하고, 페이지 없는 모드 또는 웹 help popup의 즉시 출력은 허용한다.

사용자 정의 명령이 숨겨진 helper에서 별도 대기를 시작한다면 `shortcut_completion_guaranteed = False`로 완료 계약을 명시해야 한다. 알려진 입력/편집/메뉴 호출과 직접 비동기 참조도 검사하며, 예상하지 못한 비동기 반환은 방어적으로 남은 실행을 취소한다. 임의 Python 함수의 모든 부수 작업을 정적으로 증명하는 범용 분석기는 만들지 않는다. 단독 progressive 실행은 기존 엔진 수명을 따른다.

다중 후보가 있더라도 후보 존재만으로 묶음을 실행하지 않는다. 기본 Evennia 다중 매칭 핸들러는 후보 안내만 하고 다음 세그먼트로 진행한다. 임의 후보 실행·추가 입력 대기를 할 수 있는 사용자 정의 다중 매칭 핸들러는 간접 실행에서 실행 전에 거절한다. 하나의 일반 Command가 최종 선택되면 정상 실행하고, `해`가 최종 선택되면 새 묶음 생성으로 중단한다. 최상위 직접 입력의 기존 다중 매칭·묶음 정책은 바꾸지 않는다.

## 도움말 출력

`해 도움말`, `줄임말 도움말`, `해지 도움말`, `단축어 도움말`은 기능 설명 → 사용법 → 예시 → 실행 규칙 → 제한 → 관련 도움말 순서다. 입력 예와 관련 도움말은 command token으로 강조하고, 일반 게임 명령의 사용법·별칭·단축어 형식은 유지한다. 추가 입력이 필요한 progressive 명령은 실행 뒤 선택·확인 응답을 기다리는 명령이다. 입력할 때 인자를 함께 지정하는 `북 보기`는 이에 해당하지 않는다.

## 전체 삭제 안전 계약

각각 별개의 직접 입력만 허용한다.

```text
모두 삭제 줄임말
모두 삭제 확인 줄임말
```

요청만으로 삭제하지 않는다. 요청 후 60초가 지나기 전에 별도의 직접 입력으로 확인하고 전체 목록 fingerprint가 일치해야 한다. 문자열·구형 리스트·None 등 JSON 호환 값을 포함한 전체 딕셔너리를 정렬해 결정적으로 직렬화한다. 비문자열 키·비호환 객체·손상된 저장 영역에서는 요청을 만들지 않는다. 빈 딕셔너리에도 요청을 만들지 않는다.

요청은 캐릭터 ndb에만 저장한다. 새 요청이 이전 것을 대체하며 직접 확인은 성공·실패 모두 일회성으로 소비한다. 등록·수정·삭제 등 목록이 바뀌면 fingerprint 불일치로 거절한다. 간접 요청·확인은 pending 읽기·변경·소비 전에 거절한다. 최종 문자열만으로 직접 입력 자격을 부여하지 않고 파서가 발급한 `Invocation`과 실행 컨텍스트로 출처를 구분한다. 변수로 같은 문자열을 생성해도 간접 입력이다.

유효한 확인은 하나의 프로필 저장 트랜잭션에서 `command_shortcuts = {}`만 변경한다. 다른 진행·아이템·회복 데이터는 바꾸지 않는다. 로그아웃·정상 서버 종료·프로세스 재시작에서는 pending이 무효다. 요청은 캐릭터 사이에서 공유하지 않는다.

## 프로필 v11과 구형 데이터

신규 문자열은 실행 후보이며 잘못된 문자열은 선택될 때 오류다. v7~v10은 안전한 리스트만 문자열로 이전한다. `["장비"]`는 `"장비"`, `["북 보기", "상태"]`는 `"북 보기, 상태 해"`다. 공통 파서가 기존 경계·순서·개수를 재현하지 못하면 원본 리스트를 보존한다. `["안녕, 반가워 말", "상태"]`처럼 모호한 콤마는 변환하지 않는다. v11에 남은 리스트는 다시 자동 변환하지 않고 비활성으로 읽는다.

v8의 저장 어휘·예약 이름 변환과 v10의 기술 명령 변환은 정상 항목에만 기존 정책을 적용한다. v8은 `가/가방 → 소지품`, `치료 → 진료`, `heal → 응급처치` 등의 당시 해석을 유지한다. v10은 `붕대/응급처치 → 붕대 사용`, `방어/guard → 견제`와 충돌 이름 `_개인[번호]` 보존을 유지한다. 채팅·대상 문자열은 바꾸지 않는다. 당시 고정 전역 변환표와 exact 참조 갱신만 적용하며 v11은 새 이름 변경·참조 복구를 추가하지 않는다. 성장 정규화는 [기존 캐릭터 호환성](progression.md#기존-캐릭터-호환성)을 따른다.

비정상 개별 값·이름·정규화 충돌은 원본을 보존한다. `Gear`와 `gear`가 함께 있으면 둘 다 목록에 표시하되 해당 이름의 실행·개별 수정·삭제·재등록을 차단한다. 유일한 `Gear`라면 유효한 `gear 상태 줄임말` 등록으로 정규화 키와 문자열을 원자적으로 교체한다. 실패 시 원본 키도 유지한다.

저장 영역이 딕셔너리가 아니거나 키가 비문자열이면 개인 기능만 비활성/저장 오류로 안내한다. 일반 명령과 다른 게임 데이터는 정상 처리한다. 임의 초기화·비정상 값 삭제·JSON 비호환 객체 복구는 하지 않는다. 전체 목록은 100항목까지 이름·활성/비활성·충돌·120자 미리보기와 총 개수·생략 개수를 표시한다. 상세는 2,000자까지만 표시하고 원본은 바꾸지 않는다.

`profile_snapshot()`과 파서 조회는 사본에서만 변환하고 DB를 저장하지 않는다. 기존 프로필 저장 경계에서 중간 결과 없이 v11과 다른 기존 마이그레이션을 원자적으로 저장한다.

## 전역 단축어와 제외 범위

`commands/aliases.py`의 기존 정적 전역 단축어는 정확한 전체 입력에 한 번만 변환한다. `상 → 상태`, `장 → 장비`, 방향 초성은 그대로다. 각 세그먼트도 같은 우선순위를 따른다. 내부 `ARGUMENT_SHORTCUTS`는 테스트용 변수 정의 기반이며 현재 새 전역 입력을 추가하지 않는다. 단일 실제 명령만 지원하고 다른 전역/개인 정의로 중첩하지 않는다. 같은 변수·실행량·출처 정책을 사용한다.

조건·반복·지연·예약·자동 길찾기·병렬 순차 실행·대기열 합치기·전체 묶음 rollback·따옴표 인자 그룹·콤마 이스케이프·계정 공용 설정·웹 관리 UI·import/export는 제외한다. 게임 전투·회복·상점 밸런스는 변경하지 않는다.
