# 첫 탐사 테스트

## 시작

브라우저에서 새 탐사자 계정을 만든다. 관리자 계정 대신 일반 계정으로 테스트한다.
같은 계정은 한 세션만 허용하므로 두 사람 테스트에는 서로 다른 계정을 사용한다.

## 기본 경로

1. 부두: '대화 윤대장'으로 임무 수락.
2. '북'으로 초지 이동. '공격 어린청소룡', '강타'로 사냥.
3. 전리품을 '가방'으로 확인하고 '착용 강철마체테'. 드롭이 없으면 부두에서 구매하거나 재료로 교환.
4. 초지에서 '동'으로 수송차에 가서 '조사 보급상자'. 붕대는 한 계정당 한 번 지급.
5. 초지 → 북(오솔길) → 동(관리동). '조사 정비기록'.
6. 관리동 → 동(발전실). 회수부품 3개로 '수리 발전기'.
7. 부두에서 장비·붕대 준비. Lv.4, 탐사카빈, 강화조끼를 권장한다.
8. 오솔길 → 북(습지) → 북(능선). '공격 능선의우두머리'.
9. 우두머리가 몸을 낮춘 뒤에는 '방어', 체력이 낮으면 '회복'. 이 명령은 다음 차례에 적용된다.
10. 처치 후 '귀환', '대화 윤대장'으로 보상.

## 추가 확인

- 전투 중 방향 이동·귀환·장비 변경이 거절되는가?
- 반복 공격 입력으로 전투 속도가 빨라지지 않는가?
- 다른 탐사자가 같은 사냥터에서 독립적으로 사냥할 수 있는가?
- 정상 종료 후 재접속했을 때 체력·가방·현재 위치·임무가 유지되는가?
- 같은 보급상자·임무 보상이 두 번 지급되지 않는가?
- 실패한 구매가 재화나 가방을 바꾸지 않는가?
- 한글 조합 중 Enter가 명령을 너무 일찍 전송하지 않는가?
- 좁은 화면에서도 명령 입력과 사냥·회복 버튼을 사용할 수 있는가?
