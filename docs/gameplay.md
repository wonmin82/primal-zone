## 게임 시작과 기본 조작

[웹 화면](http://127.0.0.1:8701/webclient/)에서 이름·비밀번호를 정하고 **새 탐사자 만들기**를 선택하세요. 기존 계정은 **접속하기**를 사용합니다.
새 탐사자는 출정 대기실에서 탐사용 벌목도·탐사대 작업복과 붕대를 갖고 시작합니다. `점수`, `가진거`, `장비`로 준비를 확인하세요.

### 첫 사냥

출정 대기실에서 `남` → 본부 중앙 로비, `서` → 탐사대 부두, `북` → 바람 부는 초지로 이동합니다.
부두에서 먼저 임무를 받고 사냥해 보세요.

```text
도움
남
서
윤대장 대화
북
어린청소룡 때려
```

공격 후에는 기본 공격이 자동으로 이어집니다. **처치 메시지가 나온 뒤** `시체에서 모두 가져`, `가진거`를 입력하세요.
적이 재생성 대기 중이거나 다른 그룹이 점유했다면 기다리거나 다른 사냥터를 이용합니다. 어둠 때문에 적·전리품을 찾지 못하면 [손전등](#날씨시간조명손전등)을 먼저 확보하세요.

웹 주변 행동 버튼은 직접 입력과 같은 서버 명령을 보냅니다. 로그의 색 있는 단어 자체는 클릭 링크가 아닙니다.
HP·정신력·XP meter는 현재 상태를, 텍스트의 `[ 60/60 · 40/40 ] >`는 체력·정신력과 입력 완료를 보여 줍니다.
빈 Enter로 최신 값을 다시 볼 수 있습니다. 빈 입력은 명령 기록에 남지 않고, ↑/↓는 이전 명령을 불러옵니다. 자동 전투마다 새 prompt가 붙지는 않습니다.

## 명령 입력과 도움말

정식 명령·별칭과 이전 이름 제거 목록은 [명령 어휘 기준](commands.md)을 따릅니다.

기본 순서는 **대상 + 행동**입니다. 대상 이름에 공백이 있어도 됩니다. 별칭도 `어린청소룡 쳐`처럼 뒤에 씁니다.
`때려 어린청소룡` 같은 전치형 게임 명령은 지원하지 않습니다. `북`, `점수`, `강타`처럼 대상이 없으면 단독으로 입력하세요.

| 원하는 행동 | 입력 예시 |
| --- | --- |
| 주변·대상 관찰 | `봐`, `윤대장 봐`, `절단마체테 봐` |
| 정보 조회 | `점수`, `능력`, `경험치`, `기술`, `장비`, `가진거`, `임무`, `파티` |
| 전체·분류 도움말 | `도움`, `이동 도움`, `전투 도움`, `아이템 도움`, `성장 도움`, `교류 도움`, `편의 도움` |
| 상세 사용법 | `입력 도움`, `때려 도움`, `치료 도움`, `목록 도움`, `파티 도움` |
| 별칭으로 도움말 | `ㅂㄷ 도움`, `소 도움` |

`가진거`는 `가진`, `소`, `소지`, `소지품`으로도 조회합니다. 대상 보기는 설명과 지금 사용할 수 있는 행동을 안내합니다.

### 같은 이름의 대상과 번호

번호 없이 입력하면 기본 대상 하나를 선택합니다. `갈퀴사냥룡 2 때려`는 두 번째 적, `갈퀴사냥룡 모두 봐`는 같은 종류 전부의 관찰입니다.
번호는 현재 보이는 대상의 임시 순서이며 다른 대상이 사라지면 바뀔 수 있습니다. 실행 전에 보기를 다시 확인하세요.
공격·대화·조사·수리·무장·착용은 한 대상만 지정합니다. 여러 출처의 전리품은 [회수 문법](#전리품과-보급칩)을 사용합니다.

### 채팅

`안녕하세요 말` 또는 `'안녕하세요`로 같은 방의 탐사자에게 말합니다. 내용은 1~300자입니다.
작은따옴표는 앞에 하나만 붙이며 뒤의 모든 내용은 채팅입니다. `'안녕하세요 말`은 마지막 `말`까지 전송합니다. 채팅의 콤마도 보존합니다.

## 이동·지도·탐색

| 방향 | 정식 입력 / 영문 / 고정 단축어 |
| --- | --- |
| 북·북동·동·남동 | `북/n/ㅂ` · `북동/ne/ㅂㄷ` · `동/e/ㄷ` · `남동/se/ㄴㄷ` |
| 남·남서·서·북서 | `남/s/ㄴ` · `남서/sw/ㄴㅅ` · `서/w/ㅅ` · `북서/nw/ㅂㅅ` |
| 수직·특수 출구 | `위/u/ㅇ`, `아래/d/ㅁ/아`, `계단`, `나가기`, `승강기`, 승강기 안의 `1층`~`5층`·`옥상` |

실제 출구가 있는 방향만 이동합니다. Exit의 이름·별칭은 인자 없이 입력해야 합니다. `북 봐`와 `북 보`는 이동 없이 인접 장소를 정찰합니다.
`출구`(`exits`)는 목적지의 공개 가능한 이름과 현재 이동 제한을 보여 주며 전투 중에도 조회할 수 있습니다. 방문한 장소 이름도 관찰 권한에 따라 제한될 수 있습니다.

`지도`는 탐사 지역의 방문 기록과 연결을 확인하는 명령입니다. 진행 조건이 잠긴 경계 너머는 정찰로도 공개하지 않습니다.
인접 정찰에서는 종류·수량만 보이고 탐사자 이름, HP·대상 번호·전리품·상자 내용·작은 표식·바닥 물건은 보이지 않습니다. 자세한 대상은 이동한 뒤 `봐`로 확인하세요.
정찰만으로 방문·임무가 진행되지는 않습니다.

방과 웹의 나침반은 평면 3×3 위치를 유지합니다. 중앙 `o/^/v/X`는 수직 출구 표시이며 조작 버튼이 아닙니다. 위·아래 중 하나라도 제한되면 중앙 표시가 황색입니다.
웹 이동 버튼도 실제 출구의 권한·전투·진행 제한을 따릅니다. 본부의 층 이동은 [본부 안내](#본부와-탐사-지역)를 보세요.

## 전투와 기술

`어린청소룡 때려` 또는 `갈퀴사냥룡 2 때려`로 교전을 시작합니다. 적이 방에 있다는 이유만으로 공격받지는 않습니다.
기본 공격은 약 2.5초마다 자동으로 진행되며 공격 명령을 반복해도 빨라지지 않습니다. 적 HP는 같은 방의 모든 탐사자가 공유합니다.

| 기술·행동 | 사용 방법과 결과 |
| --- | --- |
| 공격·방어 | 훈련하는 패시브 기술입니다. 액티브 `방어` 명령은 없습니다. |
| `강타` | 다음 기본 공격을 강한 근접 공격으로 바꿉니다. 총기로는 사용할 수 없습니다. |
| `쏴` | 총기가 필요하며 다음 공격의 피해·관통을 높입니다. |
| `간파` | 공격 기회 하나로 분석하고 이후 한 공격의 피해·관통을 높입니다. 재사용 대기 10초입니다. |
| `견제` | 다음 공격으로 피해를 주며 적의 공격력을 일정 공격 횟수 동안 낮춥니다. 재사용 대기 10초입니다. |
| `치료`, `철수 치료` | 자신 또는 같은 방 파티원의 체력을 정신력으로 회복합니다. |
| `호흡` | 정신력을 회복합니다. |
| `붕대 사용` | 붕대 한 개로 HP 20을 회복합니다. 정신력을 소비하지 않습니다. |
| `도망` / `flee` | 교전에서 이탈합니다. 일반 이동과 `귀환`은 전투 중 사용할 수 없습니다. |

전투의 기술·붕대 회복은 다음 자동 공격 한 차례를 대신합니다. 같은 차례에 다른 기술을 입력하면 예약 행동을 덮어쓸 수 있습니다.
비전투의 치료·호흡·붕대는 즉시 실행됩니다. 기술은 정신력·장비·재사용 조건을 만족해야 하며 부족하면 필요한 양을 안내합니다.
간파·견제 등 cooldown은 로그아웃·재훈련으로 초기화되지 않습니다.

견제는 탐사자마다 같은 적에게 하나씩 유지하며 동료의 효과와 함께 적용됩니다. 일반 적의 최종 감소율은 약 56.95%, 보스는 약 32.92%까지입니다.
보스는 각 효과를 절반으로 받고, 적이 공격할 때 효과의 남은 횟수가 줄어듭니다. 교전이 끝나면 사라집니다.
Rank별 비용·강타/호흡의 재사용 시간과 계산식은 [성장·전투 설계](progression.md)를 확인하세요.

### 총기와 재장전

소유한 탐사카빈·호환 탄창·탄약을 예로 들면 다음처럼 사용합니다. 같은 물건이 여러 개면 `2` 등 현재 번호를 붙이세요.

```text
탐사카빈 재장전
탐사카빈에 카빈표준 2 장전
탐사카빈에서 탄창 꺼내
카빈표준 2에 카빈탄 넣어
카빈표준 2 채워
카빈표준 2에서 카빈탄 꺼내
```

`재장전`은 소지한 호환 탄창 중 잔탄이 가장 많은 것을 선택합니다. 지금 탄창보다 잔탄이 같거나 적으면 유지합니다.
실제 발사에 1발을 사용합니다. 빈 총기 발사는 공격 기회만 쓰고 정신력·cooldown을 소비하지 않습니다.
성공한 전투 재장전은 기회 하나를 쓰지만 실패·무변경은 쓰지 않습니다. 탄창 분리·탄약 채우기·전량 꺼내기는 비전투에서만 가능합니다.
상점 총기는 가득 찬 표준 탄창을 포함하지만 적이 떨어뜨린 총기는 부분 장전 상태입니다. 탄종·용량·상세 동작은 [광원·총기](lighting-firearms.md)를 따릅니다.

## 체력·정신력·회복

신규 탐사자는 HP 60·정신력 40으로 시작합니다. 최대 정신력은 레벨 기본값에 지혜 투자×4를 더합니다.
레벨 상승은 최대 자원의 증가분만큼 현재 값도 올리지만, 특성 배분·장비 변경·재훈련으로는 무료 회복하지 않습니다. 정신력 0 자체의 별도 불이익은 없습니다.

| 회복 수단 | 조건과 효과 |
| --- | --- |
| `치료` / `힐` / `heal` | 자신의 최대 HP·치료 Rank·지혜 투자에 따라 회복합니다. 정신력을 씁니다. |
| `붕대 사용` | 한 개 소비, HP 20 회복. HP가 가득하면 소비하지 않습니다. |
| `야전식량 먹어` | 비전투에서 한 개로 HP 12 회복합니다. |
| `정제수 마셔` | 비전투에서 한 개로 HP 6 회복합니다. |
| `진료`, `의무관 진료`, `의무관에게 진료` | 의무실의 무료 서비스로 HP만 가득 채웁니다. `treat` 별칭도 지원합니다. |
| `휴식`, `침대 휴식`, `침대에서 휴식` | 의무실의 무료 서비스로 HP·정신력을 채웁니다. `rest` 별칭도 지원합니다. |

음식·음료는 부족한 HP까지만 회복하며 가득하면 소비하지 않습니다. 배고픔·갈증은 없습니다.
진료·휴식은 실제 의무관·침대가 보이는 안전한 방의 비전투 상태에서 이용합니다. 의사·병상 별칭도 지원합니다.
대상을 생략하려면 해당 제공자가 하나여야 하며 여러 개면 이름·번호를 지정합니다. 두 서비스는 붕대·보급칩을 사용하지 않습니다. 휴식은 두 자원이 모두 가득할 때 거절합니다.

비전투 `귀환`은 본부 옥상으로 이동합니다. `승강기` → `3층` → `북`으로 의무실에 가서 회복하세요.
의무실에서 `남` → `승강기` → `1층` → `서`로 부두에 돌아옵니다.
패배하면 최대 10칩을 잃고 의무실에서 체력 1로 구조됩니다. 장비·경험치·소지품·진행은 보존되며 이후 직접 진료·휴식을 사용하세요.

### 자연회복과 재접속

기본 HP 회복은 비전투에서 분당 `2 + 최대 HP/60`, 정신력은 전투 중에도 분당 `4 + 최대 정신력/20`입니다.
비전투 장소 보너스(HP/정신력)는 의무실 +6/+2, 본부 중앙 로비 +2/+2, 폐쇄된 관리동 +2/+1, 옥상과 주변 여덟 구역 +0/+2입니다.
실제 장착한 회복 장비도 보너스를 제공합니다. 범용 시간제 소비품 회복 buff는 아직 없습니다.

10초 경계마다 정수량을 회복합니다. 이동·장비 변경·빈 Enter 반복으로 즉시 회복하지 않으며 소수량과 남은 시간은 누적됩니다.
로그아웃 위치의 보너스와 만료 전 효과는 오프라인 경과에도 계산합니다. 새 로그인·재로그인은 출정 대기실에서 시작하고 살아 있는 세션의 서버 reload는 기존 위치를 유지합니다.
자동 사냥 보상은 오프라인에 지급되지 않습니다. 연결이 끊겨도 서버가 단절을 인지하기 전까지 전투가 진행될 수 있습니다.
피해 입은 적은 교전 종료 후 15초 유예 뒤 분당 `8 + 최대 HP/15`로 점진 회복하며 즉시 가득 차지 않습니다.

## 장비·아이템·보관

장비는 **자동 교체되지 않습니다**. 기존 무기를 해제하거나 방어구를 벗은 뒤 새 장비를 장착하세요.
다음은 해당 장비를 얻은 뒤의 교체 예시입니다.

```text
탐사용 벌목도 해제
절단마체테 무장
탐사대 작업복 벗어
강화방호조끼 착용
절단마체테 주무기
장비
```

무기는 `무장`(`wield`), 방패·보조장비·착용 장비는 `착용`(`입어`, `입`)을 사용합니다. `equip` 별칭은 지원하지 않습니다.
같은 개별 장비는 `절단마체테 2 봐`처럼 구분합니다. 두 무기를 장착하면 `<무기> 주무기`로 실제 공격에 쓸 하나를 선택하며 두 무기의 기본 공격력을 합산하지 않습니다. 무기 없이 맨손 공격도 가능합니다.
손은 총 두 칸입니다. 양손 무기는 다른 손 장비와 함께 사용할 수 없고, 한손 무기는 다른 무기·방패·보조장비와 조합합니다. 방패끼리·보조장비끼리·방패+보조장비는 조합하지 못합니다.
머리·목·몸·장갑·허리·다리·발·장신구는 각 하나, 반지는 둘이며 동일한 반지 두 개도 가능합니다. 계산·슬롯 상세는 [장비 설계](equipment.md)를 보세요.

### 물건 전달과 보관

아래 `탐사자`는 같은 방의 실제 상대 이름으로 바꾸세요. 본부 2층 중앙에서 `서` → `북`이면 보관실입니다.

| 조작 | 입력 예시 |
| --- | --- |
| 버리기·회수 | `붕대 버려`, `붕대 모두 버려`, `붕대 가져` |
| 상대에게 전달 | `탐사자에게 붕대 줘`, `탐사자에게 붕대 모두 줘` |
| 공용 보관 | `보관상자에 붕대 모두 넣어`, `보관상자에서 붕대 꺼내` |
| 개인 보관 | `개인 보관함에 강화방호조끼 넣어`, `개인 보관함 봐`, `개인 보관함에서 강화방호조끼 꺼내` |

이전·보관·장비 해제·음식/음료 사용은 비전투에서만 가능합니다. 전달은 같은 방의 보이는 다른 비전투 탐사자에게만 가능하며 자신·NPC에게는 줄 수 없습니다.
수량은 기본 한 개 또는 `모두`로 지정합니다. 개별 물건은 번호로 고릅니다. 공용 상자는 다른 탐사자도 이용하고 개인 보관함은 자신의 물품만 보여 줍니다. 현재 보관 용량 제한과 보관함 중첩 기능은 없습니다.
임무용 밀림 신호전지는 버리기·전달·보관이 금지됩니다. 보스 임무의 고유 장비는 장착·해제·개인 보관만 가능하며 공용 보관·판매·소각·양도·버리기는 금지됩니다.

## 전리품과 보급칩

경험치는 처치 즉시 받지만 보급칩·물건은 시체에서 직접 회수합니다. 아래는 기본·번호·전체 선택 예시입니다.

| 범위 | 입력 |
| --- | --- |
| 바닥의 한 개 / 두 번째 / 같은 종류 전부 | `회수부품 가져` · `회수부품 2 가져` · `회수부품 모두 가져` |
| 바닥 전체 | `모두 가져` (`전리품 모두 가져`) |
| 기본 시체 한 구 | `시체 봐` · `시체에서 회수부품 가져` · `시체에서 모두 가져` |
| 두 번째 시체 | `시체 2 봐` · `시체 2에서 모두 가져` |
| 모든 시체 | `시체 모두 봐` · `모든 시체에서 회수부품 모두 가져` · `모든 시체에서 모두 가져` |

`시체에서`는 기본 시체 하나만 고릅니다. 시체 번호는 적 종류별이 아닌 방 전체 순서입니다.
여러 시체를 선택하면 가져올 대상에도 `모두`를 붙입니다. `전체 회수부품 가져` 같은 앞쪽 전체 문법은 지원하지 않습니다.
번호 없는 물건·번호 지정은 한 개, `<물건> 모두`는 선택한 범위의 같은 종류 전부입니다. 상세 보기에 현재 회수 명령이 표시됩니다.

시체는 처치 30초 뒤 남은 전리품을 바닥으로 옮기고, 적은 처치 약 45초 뒤 재생성됩니다. 배정 보호는 처치 후 120초이며 바닥 이동에도 유지됩니다.
보호 중 회수 요청은 실제 배정자에게 지급합니다. 다른 그룹의 보호된 물건은 남기고 회수 가능한 것만 처리합니다. 보호 만료 후 남은 물건·칩은 요청자가 가져갑니다.
바닥 물건은 적 재생성으로 사라지지 않습니다. 내부 권리·부분 회수의 저장 계약은 [전리품 설계](loot-claims.md)를 따릅니다.

### 칩 전달·버리기·부분 회수

보급칩은 유일한 구매 화폐이며 단위는 **칩**입니다. `점수`·`가진거`에 잔액이 나오고 `칩 봐` 또는 `보급칩 봐`로 설명을 확인합니다.
아래 `철수`는 실제 상대 이름으로 바꾸세요.

| 조작 | 입력 예시 |
| --- | --- |
| 전달 | `철수에게 칩 줘`, `철수에게 20칩 줘`, `철수에게 칩 모두 줘` |
| 버리기 | `20칩 버려`, `칩 모두 버려` |
| 바닥 회수 | `칩 가져`, `20칩 가져`, `칩 2 가져`, `칩 모두 가져` |
| 시체 회수 | `시체에서 20칩 가져`, `시체 2에서 칩 모두 가져`, `모든 시체에서 칩 모두 가져` |

금액 생략은 1칩, `20칩`은 금액, `칩 2`는 두 번째 회수 가능한 화폐 더미입니다. `모두`는 접근 가능한 전액입니다. 0·음수·소수·잔액 초과는 거절합니다.
전달에는 물건과 같은 비전투·같은 방·지각 조건이 적용되며 직접 버린 칩은 누구나 회수할 수 있습니다.
파티 시체의 보호된 칩을 회수하면 처치 당시 참여자의 몫을 함께 지급합니다. 요청자가 독점하지 않으며 자신의 남은 몫이 0이어도 원래 참여자는 다른 몫의 지급을 요청할 수 있습니다.
부분 회수는 남은 몫을 보존하고 탈퇴·해체·가입으로 기존 권리가 바뀌지 않습니다. 공용 보스는 기여 그룹별 몫을 보호합니다.

## 상점·정산·소각

본부의 현재 방에서 보이는 상인에게 안전·비전투 상태로 서비스를 받습니다. 부두에는 상인이 없습니다.
기본점은 T1, 전초 보급구역 출입증으로 들어가는 전초 병기고·장비고는 T2를 판매합니다. 모든 가격·획득처는 [최종 콘텐츠](final-content.md)가 기준입니다.

| 시설 | 중앙에서 경로 | 판매 내용 |
| --- | --- | --- |
| 2층 보급품 상점 / 보급관 | `북` | 손전등 35칩, 건전지 8칩, 붕대 10칩, 야전식량 5칩, 정제수 3칩 |
| 2층 자원 정산소 / 정산관·소각기 | `동` → `북` | 일반 회수부품 정산·물품 폐기 |
| 5층 기본 병기점 / 무기상 | `동` → `북` | T1 무기·방패·보조장비·탄창·탄약 |
| 5층 기본 장비점 / 방어구상 | `서` → `북` | T1 착용 장비 |
| 5층 전초 병기고·장비고 | 동쪽/서쪽 끝 복도에서 `북` | T2 장비·병기. 남쪽 예약 시설은 출입증이 있어도 폐쇄 |

| 조작 | 입력 예시 |
| --- | --- |
| 목록 | `목록`, `보급관 목록`, `무기상 목록` |
| 구매 | `붕대 사`, `보급관에게 붕대 사`, `절단마체테 사`, `방어구상에게 강화방호조끼 사` |
| 가치·매입가 | `절단마체테 가치`, `무기상에게 절단마체테 가치` |
| 판매 | `붕대 팔아`, `붕대 3개 팔아`, `붕대 모두 팔아`, `절단마체테 2 팔아` |

`목록`은 상인이 하나일 때 자동 선택합니다. 대상 없는 구매는 해당 물품 판매자가 하나여야 하며 여럿이면 이름·번호로 지정하세요.
각 상인은 자기 목록만 판매합니다. 재고는 무한이고 일반 물건은 한 개씩 구매합니다. 탄약은 9mm 12발·5.56mm 20발·7.62mm 8발 묶음이며 총기는 가득 찬 표준 탄창 포함 상품입니다.
판매 목록과 매입 종류는 별개여서 현장 획득 장비도 해당 기본점에 판매할 수 있습니다. 장착한 물건은 먼저 해제합니다.
일반 매입가는 기준가 절반 내림이며 별도 매입가가 우선합니다. 탄창은 잔탄 가치도 포함합니다. 총기는 탄창을 분리한 뒤 판매·소각해야 합니다.
임무 물품·출입증은 상점에 판매하지 못하고, 일반 회수부품은 정산관에게 교환합니다.

### 회수부품 정산

일반 회수부품은 사냥에서 얻는 경제 재료이며 전달·공용/개인 보관도 가능합니다. 정산관이 보이는 안전·비전투 상태에서 **1개당 10칩**으로 정산합니다.

| 조작 | 입력 예시 |
| --- | --- |
| 환율 | `정산관 환율` |
| 정산 | `회수부품 교환`, `회수 부품 교환`, `회수부품 10개 교환`, `회수부품 모두 교환` |
| 제공자 지정 | `정산관에게 회수부품 10개 교환` |

생략하면 한 개, `N개`는 정확한 수량, `모두`는 현재 소지한 전체입니다. 정산·스택 판매·소각에는 `N개`가 가능하지만 이전·보관에는 기본 한 개/`모두` 문법을 사용합니다.
정산관을 생략하려면 하나만 있어야 하며 여럿이면 이름·번호로 고릅니다. 회수부품을 가진 것만으로 상점 물건을 구매할 수 없고 자동 환전도 없습니다.
발전기는 별도 **정비용 회수부품 3개**를 사용합니다. 정비부품은 제출 외 판매·정산·소각·이전이 금지되며 일반 회수부품과 구분됩니다.
정산소에서 `남` → `서` → `승강기` → `5층` → `동` → `북`이면 기본 병기점입니다.

### 출입증과 소각

통신탑 최종 보고에서 윤대장이 전초 보급구역 출입증, 밀림 최종 보고에서 선발대 길잡이가 특수 보급구역 출입증을 지급합니다.
완료 기록만으로 입장하지 못하며 실제 출입증이 필요합니다. 파티에 공유되지 않습니다. 분실·소각 뒤 원래 발급자에게 대화하면 출입증만 무료 재발급됩니다.
2층 정산소의 폐기물 소각기 앞에서 폐기할 수 있으며 칩·탄약은 반환되지 않습니다.

```text
붕대 소각
붕대 3개 소각
붕대 모두 소각
전초 보급구역 출입증 소각
전초 보급구역 출입증 소각 확정
```

출입증은 첫 입력으로 안내만 받고 정확한 `소각 확정`으로 삭제합니다. 임무 완료·보상은 유지되지만 접근 권한은 즉시 사라집니다.
잔탄 탄창을 소각하면 탄약도 함께 없어집니다. 상세 권한은 [출입증·접근·상점](credentials-access-shops.md)을 확인하세요.

## 성장과 재훈련

`능력`에서 힘·민첩·체질·지혜와 남은 포인트, `기술`에서 여덟 기술 Rank·훈련, `경험치`에서 누적 XP·다음 보상을 확인합니다.
특성은 기본 10에서 각각 +20까지 투자하며 Lv.126에 모두 완성할 수 있습니다. 기술은 모두 R1로 시작하고 레벨업마다 훈련 한 번을 얻어 Lv.133에 모두 완성할 수 있습니다.
사용하지 않은 훈련은 남습니다. 숙련 자동 성장이나 기술 학습의 보급칩 비용은 없습니다. 상세 효과는 `능력 도움`·각 기술 도움말과 [성장 설계](progression.md)를 보세요.

| 본부 4층 교육시설 | 중앙에서 경로 | 담당 |
| --- | --- | --- |
| 전투훈련실 | `서` → `북` | 공격·강타·힘 |
| 생존훈련실 | `서` → `남` | 방어·체질·호흡 |
| 훈련관리실 | `북` | 특성 재분배·기술 재분배·전체 재훈련 |
| 전술훈련실 | `남` | 견제·지혜 |
| 사격장 | `동` → `북` | 사격·간파·민첩 |
| 의료훈련실 | `동` → `남` | 치료 |

```text
강타 배워
타격교관에게 강타 배워
힘 4 배분
근력교관에게 힘 4 배분
훈련관리관에게 기술 재분배
특성 재분배
전체 재훈련
```

담당 교관이 보이는 안전한 방에서 비전투 중 무료로 훈련합니다. 하나면 교관 이름을 생략할 수 있고 여럿이면 지정하세요. 기술은 한 번에 Rank 1, 특성은 요청량 전체가 가능한 때만 배분됩니다.
교관 보기·대화는 담당 역할과 입력을 안내하며 현재 투자 상태는 `기술`·`능력`에서 확인합니다. 전문 교관은 직접 훈련, 훈련관리관은 재분배를 맡습니다.
재훈련은 선택한 특성/기술/전체 투자만 돌려주고 캐릭터·탐사 기록을 유지합니다. HP·정신력을 채우거나 cooldown을 초기화하지 않습니다.
현재 프로필은 v11이며 옛 성장·기술 정규화와 안전한 줄임말 이전을 유지합니다. 운영자가 처리하는 아이템 DB 이전은 별도의 [migration](item-migration.md)입니다.

## 파티와 멀티플레이어

함께 사냥하려면 아래 `친구이름`을 실제 탐사자 이름으로 바꾸어 초대하고 상대가 수락합니다.

| 목적 | 입력 |
| --- | --- |
| 초대·응답·조회 | `친구이름 파티초대`, 상대의 `파티수락` 또는 `파티거절`, `파티` |
| 파티장 관리 | `순번 파티분배`, `친구이름 파티장위임`, `친구이름 파티제외` |
| 탈퇴 | `파티탈퇴` |

최대 4명이며 초대는 60초간 유효합니다. `파티거절`로 거절할 수 있습니다. 초대·제외·위임·분배 설정은 파티장이 합니다.
전투 중 새 파티 생성·가입은 거절되고 탈퇴·제외는 해당 탐사자의 참여도 정리합니다. 파티장의 명시적 탈퇴는 남은 가입 순서로 승계하고 로그아웃은 승계 사유가 아닙니다.
일반 적은 첫 탐사자/파티가 점유하고 다른 그룹의 공격을 거부합니다. 공용 보스에는 여러 그룹이 참여할 수 있습니다. 보스는 참여 인원에 따라 HP가 늘어나며 솔로 진행도 가능합니다.

처치 때 피해 기여가 있고 같은 방에서 접속·교전 중이며 최근 15초 안에 행동한 탐사자만 보상 대상입니다. 원격·AFK·미참여 파티원은 받지 못합니다. 지원·치유만으로 최초 보상 자격이 생기지는 않습니다.
경험치·칩은 그룹 피해 기여 비중, 파티 내부는 적격 참여자 균등으로 배분합니다. 실물은 참여자 순번이며 누구나 회수를 요청해도 배정자에게 들어갑니다.
아이템 수가 적으면 모든 그룹에 물건이 돌아가지 않을 수 있습니다. 막타·첫 회수자가 보상을 독점하지 않습니다. 현재 분배는 순번만 지원하며 자유/주사위/파티장 분배와 안전 거래창은 없습니다.

## 개인 줄임말과 묶음 명령

`단축어` 또는 `전역 줄임말`로 고정 목록을 확인합니다. 정보는 `상/능/기/장/소`, 이동은 여덟 방향 초성입니다. 옛 `가`는 고정 단축어가 아니며 개인 이름으로 등록할 수 있습니다.
개인 줄임말은 캐릭터별 설정입니다. v1.14는 다음 공식 후치형 문법을 사용합니다.

| 목적 | 입력 예시 |
| --- | --- |
| 즉석 묶음 | `점수, 장비, 가진거 해` |
| 묶음 등록·호출 | `점검 점수, 장비, 가진거 해 줄임말` → `점검` |
| 위치 인자 | `정찰 $1 봐, 점수 해 줄임말` → `북 정찰` |
| 전체 인자 | `실행 $* 줄임말` → `점수 실행` |
| 콤마 채팅 | `인사 안녕, 반가워 말 줄임말` → `인사, 점수 해` |
| 조회·삭제 | `줄임말`, `점검 줄임말`, `점검 해지` |

두 명령 이상을 콤마로 구분하고 마지막에 `해`를 붙입니다. `점검`은 저장한 묶음을, `북 정찰`은 북쪽 보기 뒤 상태를 실행합니다.
실제 명령·잠긴 명령·Exit와 고정 단축어가 개인 정의보다 우선합니다. 앞선 명령이 완료되면 현재 장소·상태에서 다음을 고릅니다.
일반 명령 실패는 다음을 계속하고 문법·변수·순환·한도 오류는 남은 실행을 중단합니다. 완료된 이동·물건 조작을 되돌리지 않습니다.

이름은 한글·자모·영문·숫자·밑줄 1~20자이고 예약 이름은 금지됩니다. 최대 100개를 저장합니다.
`$1`~`$9`는 위치 인자, `$*`는 전체 인자, `$$`는 문자 `$`입니다. 인자 안의 변수는 다시 치환하지 않으며 치환 후 콤마로 새 명령을 만들지 않습니다.
정의·호출 인자·직접 묶음은 각각 최대 2,000자, 실제 하위 실행은 10회·중첩 5·최종 문자열 합계 1,000자입니다.
같은 캐릭터의 순차 실행은 한 번에 하나입니다. 추가 응답을 기다리는 대화형·progressive 명령은 내부 실행을 지원하지 않습니다. 일반 입력은 별도로 가능하고 로그아웃하면 남은 실행이 취소됩니다.

전체 삭제는 각각 **직접 입력**합니다.

```text
모두 삭제 줄임말
모두 삭제 확인 줄임말
```

요청 후 60초가 지나기 전에 목록이 바뀌지 않은 상태에서 별도 확인해야 합니다. 확인은 한 번만 가능하고 로그아웃·재시작으로 요청은 무효가 됩니다.
`모두 해지`는 `모두`라는 개인 이름 하나만 삭제합니다. 콤마 포함 정의는 직접 등록하고 묶음 안의 콤마 채팅은 단일 줄임말로 호출하세요.
변수의 인자 수, 구형 데이터·순환·세션·비동기 완료 등 전체 계약은 [개인 줄임말 문서](command-shortcuts.md)를 따릅니다. `해/줄임말/해지/단축어 도움`로 게임 안에서도 확인할 수 있습니다.

## 날씨·시간·조명·손전등

`날씨` 또는 `환경`, 데스크톱 FIELD GUIDE의 **환경 확인** 버튼으로 시각·날씨·밤의 달·밝기·환경 시야·현재 시야를 확인합니다.
실제 1분은 게임 4분이며 하루는 실제 6시간입니다. 새벽은 05~07시, 낮 07~18시, 해질녘 18~20시, 밤 20~05시입니다. 달은 게임 28일 주기로 삭·반달·보름달을 순환하며 밤빛에만 기여합니다.
전초구역과 깊은 밀림은 같은 섬 날씨를 공유합니다. 현실 지속 시간은 맑음 20~40분·흐림 15~30분·비 10~25분·폭우 5~15분·안개 10~25분입니다.
실내에서는 바깥 날씨와 실내 밝기를 구분합니다. 장소의 환경 문장이 달라질 때만 알림이 나오며 재시작 중 지난 사건은 다시 출력하지 않습니다.

밝기·시야는 실제 대상 식별에 영향을 줍니다. 어두울 때도 출구·큰 시설은 인지하지만 작은 표식·바닥 물건은 좋은 시야, 일반 적·시체는 보통 이상이 필요합니다.
시체 내부의 전리품 확인·회수에도 좋은 시야가 필요합니다. 이미 교전 중인 상대는 계속 추적합니다. LOS·은신·원격 행동은 없습니다.

### 손전등 확보와 사용

부두에서 `북` → `동`으로 부서진 수송차에 들어가 `비상장비함 조사`로 손전등 하나·건전지 두 개를 탐사자마다 한 번 받습니다. 비상장비함은 어둠 속에서도 찾을 수 있습니다.

```text
비상장비함 조사
탐사용손전등에 건전지 넣어
손전등 켜
손전등 확인
손전등 봐
손전등 꺼
```

손전등은 각각 독립 잔량을 가지며 한 번에 하나만 켭니다. 두 번째는 `손전등 2 켜`·`손전등 2에 건전지 넣어`처럼 지정합니다.
건전지 하나는 켜진 동안 30분을 제공합니다. 잔량이 남아 있으면 새 건전지를 넣지 못합니다. 로그아웃·정상 서버 종료에는 꺼지고 잔량을 보존합니다. 손전등 자체를 다른 소유자나 보관 위치로 옮길 때도 상태를 정산합니다.
현재 방 시야는 최대 두 단계, 인접 정찰은 한 단계 개선합니다. 환경 자체의 밝기를 바꾸거나 잠긴 경계·원거리 비공개 대상을 공개하지는 않습니다.
보급관에게 손전등·건전지를 구매할 수 있고 늪지 보급품에서도 건전지 두 개를 받습니다.
부두는 상시 캠프 조명이 있고 발전기를 복구하면 관리동·발전실의 공용 조명이 켜집니다. 다른 탐사자의 개인 임무는 자동 완료되지 않습니다.
저장·전원·시설 조명 계약은 [광원·총기](lighting-firearms.md)와 [환경 설계](architecture.md#관찰-광원과-공용-시설)에 있습니다.

## 본부와 탐사 지역

본부는 활성 공간 52개, 지상 5층·옥상·계단실·공용 승강기로 구성합니다. 탐사 두 지역은 장소 15개·일반 적 6종·공용 보스 2종입니다.

| 층·지역 | 주요 용도 |
| --- | --- |
| 본부 1층 | 출정 대기실·중앙 로비·관리실·휴게실. 로비 서쪽은 부두 |
| 본부 2층 | 보관·보급품·자원 정산·소각 |
| 본부 3층 | 의무실의 진료·침대 휴식. 의료 대기실·회복실은 별도 서비스를 추가하지 않음 |
| 본부 4층 | 전문 교관 12명·훈련관리관 1명, 교육시설 6곳 |
| 본부 5층 | 기본·전초 장비/병기 시설. 다음 단계 시설은 폐쇄 |
| 옥상 | `귀환` 도착지. 여덟 주변 구역을 해당 방향으로 왕복 |
| 전초구역 | 부두의 윤대장, 첫 사냥·수송차·발전기·통신탑 임무 |
| 깊은 밀림 | 통신탑 완료·보고 후 능선 북쪽. 선발대 길잡이·표식·연구구역·두 번째 보스 |

각 층 중앙에서 `계단`으로 계단실에 들어가 `위`/`아래`로 인접 층, `나가기`로 그 층 중앙에 나옵니다.
또는 중앙에서 `승강기`에 들어가 `1층`~`5층`·`옥상`을 입력하면 즉시 해당 중앙으로 이동합니다. 승강기는 공유 공간이지만 한 사람의 선택으로 다른 승객을 이동시키지 않습니다. 호출·운행 대기·별도 하차 명령은 없습니다.
윤대장은 부두에 있습니다. 상세 배치와 운영상 출구 소유권·데이터 보존은 [본부 설계](headquarters-redesign.md)를 확인하세요.

## 임무 진행 안내 — 스포일러

이 절에는 **지역 연결·발견·임무 조건·보상**이 있습니다. 직접 탐험하고 싶다면 `임무`, `지도`, NPC 대화와 대상 보기를 따라 진행하세요.
아래 표의 입력은 각 장소에 도착한 뒤 실행합니다. 지역 전체 경로는 다음과 같습니다.

```text
[전초구역]
          탐사대 부두
               │
        바람 부는 초지 ─ 부서진 수송차
               │
    발톱 자국 오솔길 ─ 관리동 ─ 발전실
               │
          물안개 습지
               │
          통신탑 능선
               │
[깊은 밀림]                 포식자 둥지
                                 │
                           연구구역 외곽
                                 │
            버려진 관측소 ─ 거목 군락
                  │              │
늪지 샛길 ─ 밀림 입구 ─ 수몰된 도로
                  │
             통신탑 능선
```

### 통신탑 복구

| 순서·장소 | 행동과 결과 |
| --- | --- |
| 부두 | `윤대장 대화`로 임무를 받습니다. |
| 부두에서 `북` → `동`: 수송차 | `비상장비함 조사`로 광원을 준비하고 `보급상자 조사`로 붕대 2개·탐사인식표 한 개를 최초 획득합니다. |
| 수송차에서 `서` → `북` → `동`: 관리동 | `정비기록 조사`로 수리 방법을 읽습니다. |
| 관리동에서 `동`: 발전실 | `발전기 수리`로 정비용 회수부품 3개를 제출합니다. 발전기 미수리 상태에서는 보급상자가 부족분을 총 3개까지 보충합니다. 수리 후에는 지급하지 않습니다. |
| 발전실에서 `서` → `서` → `북` → `북`: 능선 | `능선의우두머리 때려`으로 보스와 싸우고 처치 뒤 `시체에서 모두 가져`로 보급칩·우두머리송곳니를 회수합니다. |
| 비전투 귀환 후 부두 | `귀환` → `승강기` → `1층` → `서` → `윤대장 대화`로 최종 보고합니다. |

보스 전에는 충분히 사냥하고 T1 장비·체력·정신력·붕대를 준비하세요. 예고를 읽고 견제·회복 행동을 다음 공격에 예약합니다.
최초 보고로 전초 보급구역 출입증과 능선포식자표식을 받습니다. 보스 랜덤 장비 대신 임무 보고로 고유 장비를 얻습니다. 반복 보고는 보상을 중복 지급하지 않습니다.

### 깊은 밀림 조사

통신탑 완료 보고 뒤 능선 북쪽으로 들어갑니다. 밀림 입구의 `선발대 길잡이 대화`로 의뢰를 받으세요.
`관측 표식 조사`는 관측소에서, `수위 표식 조사`는 수몰 도로에서 실행합니다. 수위 표식에서 밀림 신호전지 한 개를 확보합니다.
거목 군락에서 `신호 장치 조사`로 전지를 사용하면 연구구역 문이 열립니다. 열기 전에 전지를 잃었다면 수위 표식에서 다시 한 개를 받습니다.
연구구역 외곽 북쪽 둥지에서 `밀림의포식자 때려`, 처치 후 회수를 하고 입구에서 `선발대 길잡이 대화`로 보고합니다.
최초 최종 보고는 특수 보급구역 출입증·포식자비늘장식을 지급합니다. 늪지 샛길의 선택 보급품에는 정신안정모듈·건전지가 있고 강한 사냥감도 있습니다.

재생모듈·전술연산모듈 등은 사냥으로 얻습니다. 드롭은 확률이므로 한 번 처치해 얻지 못해도 오류가 아닙니다.
정확한 획득·가격·적 수치는 [최종 콘텐츠](final-content.md), 전체 임무의 수동 검증·정상 결과는 [테스트 안내](playtest.md#3-첫-임무-끝까지-진행하기)를 참고하세요.
